projects

legonardo davinci

legonardo davinci is a bare-metal printer, fully coded in C and Assembly, using LEGO bricks as ink to "print" scaled-down, images. Users upload images via a Python script, control print settings through a MangoPi interface, and monitor real-time progress, resulting in LEGO-based artwork.

migration & magnetism : research

Developed over 100 interactive geospatial maps with PyGMT and Seaborn to visualize migration data. Designed four analytical frameworks using Python and scikit-learn, revealing strong correlations (r > 0.7) between declining bird populations and weakening magnetic fields.

ossining engineering club summer program

I created an 8-week curriculum focused on C++ fundamentals and OOP, providing free weekly virtual classes via Google Meets and Zoom. This initiative attracted 10+ students each week, empowering financially disadvantaged individuals, and all students successfully completed a robot design project in CAD/C++.
